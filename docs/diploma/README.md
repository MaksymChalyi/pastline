# Матеріали диплома Pastline

Усе, що стосується кваліфікаційної роботи магістра: технічна документація проєкту, рисунки, діаграми, таблиці
результатів і (далі) текст пояснювальної записки.

## Структура

| Папка / файл | Що там |
|---|---|
| `project/architecture.md` | архітектура: модулі, дані, безпека, ключові рішення |
| `project/api.md` | REST API: ендпоінти, коди помилок |
| `project/running.md` | запуск локально, тести, бенчмарк, онлайн-демо |
| `project/experiment.md` | методика експерименту і де лежать результати |
| `project/results-tables.md` | таблиці результатів (**генеруються**, вручну не редагувати) |
| `figures/` | рисунки результатів, PNG 300 dpi (**генеруються**) |
| `diagrams/` | діаграми: `.mmd` — джерело (Mermaid), `.png` / `.svg` — для вставки в записку |
| `tools/make_figures.py` | генератор рисунків і таблиць |
| `reference/` | приклади дипломів і документи кафедри — **лише локально, не в Git** (`.gitignore`) |

Що потрібно знати про сам проєкт, лежить у `PLAN.md` (план, гіпотези, журнал рішень у розділі 14).

## Рисунки результатів

Після будь-якого нового прогону бенчмарку (`docs/experiments/results/`) — з кореня репозиторію:

```
pip install matplotlib
python docs/diploma/tools/make_figures.py
```

Скрипт бере найновіші `run-*-and.json`, `run-*-or.json` і `run-ask-*.json` і перезаписує рисунки й таблиці.
Колір режиму однаковий на всіх рисунках: лексичний — синій, семантичний — помаранчевий, гібридний — зелений.
Варіант OR і негативні результати мають штрихування, тож рисунки читаються і в чорно-білому друці.

| Файл | Що показує |
|---|---|
| `fig-mrr-by-query-type.png` | MRR@10 трьох режимів за типами запитів |
| `fig-hit1-by-query-source.png` | Hit@1 за джерелом запитів (автор / мовні моделі) |
| `fig-lexical-operator-ablation.png` | вплив оператора AND / OR на лексичний і гібридний пошук |
| `fig-search-latency.png` | затримка p50 / p95 за режимами (логарифмічна шкала) |
| `fig-ask-outcomes.png` | результати Ask Pastline: відповіді, відмови, вигадані посилання |

## Діаграми

| Файл | Що показує |
|---|---|
| `architecture` | модулі бекенду, клієнт, БД і два провайдери AI |
| `er` | схема БД: users, journal_entries, entry_embeddings |
| `hybrid-search` | послідовність гібридного пошуку з RRF |
| `ask-sequence` | послідовність Ask Pastline з перевіркою джерел |
| `indexing` | імпорт і фонова індексація векторів |
| `deployment` | локальне середовище експерименту й онлайн-демо |

Джерело кожної діаграми — текстовий `.mmd`; GitHub показує його як діаграму. Щоб перегенерувати картинку після
зміни: вставити вміст `.mmd` на https://mermaid.live і експортувати PNG, або

```
npx -y @mermaid-js/mermaid-cli -i docs/diploma/diagrams/er.mmd -o docs/diploma/diagrams/er.png -s 3
```

## Вимоги кафедри (з методички)

- Обсяг записки магістра без додатків: **90–100 сторінок**.
- Орієнтовна структура: 1) актуальність, аналоги, постановка задачі; 2) аналіз методів і засобів, обґрунтування
  стеку; 3) розробка продукту і тестування; 4) за потреби — експлуатація.
- Усі запозичення — з посиланням у квадратних дужках [N] на список джерел; робота проходить перевірку на плагіат.
