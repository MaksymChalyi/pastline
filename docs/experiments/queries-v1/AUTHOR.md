# Запити автора

Файл `author.json`: 10 запитів, які ви пишете самі, своїми словами, до будь-яких подій із
`targets.json` (поле `sentence`). Бажано різні теми і хоча б 2-3 англійською.

Формат такий самий, як у `claude.json`, але без id (його додасть раннер):
[
  {"type": "paraphrase", "lang": "uk", "text": "ваш запит", "targets": ["T100"]}
]

type: exact (слова з тексту дослівно), wordform (ті самі слова в іншій формі),
paraphrase (інші слова), crosslingual (інша мова, ніж запис).
targets: id подій, до яких запит. Еквіваленти іншою мовою (поле equivalents) додаються автоматично.
