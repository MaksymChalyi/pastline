# Промпт для ChatGPT і DeepSeek

Однаковий текст для обох моделей, кожна в новому чаті без історії. Результат зберегти як є:
відповідь ChatGPT у `chatgpt.json`, DeepSeek у `deepseek.json` (у цій папці).
У тексті диплома вказати модель і дату запиту.

---

Ти допомагаєш скласти тестовий набір пошукових запитів для персонального щоденника.

Нижче 20 подій, які людина колись записала у щоденник. Через кілька місяців вона хоче знайти
цей запис, але не пам'ятає точних слів, лише суть.

Для кожної події напиши один пошуковий запит українською так, як його ввела б ця людина:
- 2-6 слів, розмовно, без розділових знаків у кінці;
- НЕ використовуй значущі слова з опису події (іменники, дієслова, прикметники), лише інші слова
  або синоніми; службові слова (в, на, з, і) можна;
- не додавай деталей, яких немає в описі.

Потім для перших п'яти подій (T003, T007, T010, T024, T026) напиши ще по одному запиту англійською
за тими самими правилами.

Відповідай ЛИШЕ JSON-масивом без пояснень і без markdown, рівно 25 об'єктів у форматі:
[{"target": "T003", "lang": "uk", "text": "..."}, ...]
